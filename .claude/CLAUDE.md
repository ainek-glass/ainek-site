# CLAUDE.md — ainek-site

Этот репозиторий ПУБЛИЧНЫЙ (GitHub Pages). Здесь только код и фото сайта.

## Контекст — только в приватном репозитории
Весь контекст (пользователь, правила ответов, компания, заказы, решения, а также всё про сайт и маркетинг)
хранится в ПРИВАТНОМ репозитории `ainek-glass/ainek-context`.

В начале каждой сессии:
1. Подключить его: `add_repo` (owner `ainek-glass`, repo `ainek-context`, access `push`), клонировать рядом.
2. Прочитать там `CLAUDE.md` и выполнять его правила, включая протокол автообновления контекста
   (изменения контекста пушить в `main` репозитория `ainek-context`).

## Запрещено
- Записывать в этот репозиторий (файлы, коммиты, PR, issues) личные, налоговые, юридические,
  клиентские или ценовые данные. Всё это — только в `ainek-context`.
- Класть сюда .md файлы с контекстом: GitHub Pages публикует их на сайт.
